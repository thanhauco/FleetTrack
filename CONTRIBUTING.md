# Contributing

1. Fork the repository and create a feature branch.
2. Keep the Core project free of third-party dependencies.
3. Add or update unit tests under `tests/FleetTrack.Tests` for every behaviour change.
4. Run `./build.sh` before opening a pull request.
5. Follow the formatting rules in `.editorconfig`.

Commit messages use the imperative mood ("Add trip cancellation", not "Added ...").
